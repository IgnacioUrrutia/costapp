# 💰 App de Gestión de Costos y Gastos Mensuales

Bienvenido al repositorio base para el desarrollo de la aplicación de control de gastos. Este proyecto está diseñado para ser construido por una IA siguiendo las directrices estructuradas en los documentos adjuntos.

## 📁 Documentación del Proyecto

Para comenzar con el desarrollo, consulta los siguientes archivos en orden:

1. **[MASTER_PLAN.md](./MASTER_PLAN.md)**: Visión general, Stack Tecnológico y Categorías de gastos.
2. **[TASKS_BACKLOG.md](./TASKS_BACKLOG.md)**: Orden de ejecución de las tareas (Roadmap).
3. **[README_DATABASE.md](./README_DATABASE.md)**: Diseño de la base de datos Firestore y Reglas de seguridad.
4. **[README_FRONTEND.md](./README_FRONTEND.md)**: Guía de UI/UX y lógica de exportación a Excel.
5. **[README_FIREBASE_SETUP.md](./README_FIREBASE_SETUP.md)**: Pasos para configurar el entorno y desplegar la app.

## 🚀 Inicio Rápido para la IA Desarrolladora
> "Tu tarea es leer el `MASTER_PLAN.md` y comenzar con la Fase 1 descrita en `TASKS_BACKLOG.md`. Debes usar React, Tailwind y Firebase."
